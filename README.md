# زاد — رفيق حفظ القرآن والحديث

واجهة عربية حديثة تركز على:
- حفظ القرآن الكريم وتسجيل أجزاء الحفظ.
- مراجعة مختارات من الأحاديث النبوية.
- قصص الأنبياء مع مشاهد طبيعية وأجواء بصريّة خفيفة.
- مساعد فقهي توجيهي يذكّر المستخدم بأن المسائل الشرعية الدقيقة تحتاج إلى مراجعة أهل العلم.

## التشغيل

1. افتح ملف `index.html` مباشرة في أي متصفح حديث.
2. أو فكّل المشروع ثم افتح الملف من المجلد.
3. يتم حفظ تقدم الأجزاء محليًا داخل المتصفح باستخدام `localStorage`.

## ملاحظات

- هذه نسخة واجهة أولية وليست موقعًا كاملًا أو منصة فتوى.
- لا تضع أي مفاتيح أو بيانات حساسة داخل المشروع.
- في المسائل الفقهية الحساسة، راجع عالمًا مؤهلًا أو دار إفتاء موثوقة.
- لا تعتمد على الإجابة الآلية في الأحكام الشرعية أو الحديثية الدقيقة.
