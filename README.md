# زاد — رفيق رحلة الحفظ والتعلّم

تطبيق ويب عربي أولي، RTL، يضم لوحة متابعة لحفظ الأجزاء الثلاثين، وبطاقات حديث للتدرب على الاستظهار، ومكتبة قصص أنبياء وموضوعات فقه، وقسمًا مختارًا للسير والأذكار.

## التشغيل

افتح `index.html` في متصفح حديث. ومن الصفحة الرئيسية:
- `hadith.html`: أحاديث مختارة مع الراوي والمصدر، بحث حسب الموضوع، إظهار/إخفاء النص، وقائمة مراجعة محفوظة محليًا.
- `library.html`: فهرس الأنبياء المذكورين في القرآن ومداخل موضوعية لأبواب الفقه.
- `heritage.html`: نماذج مختارة من الصحابة والتابعين وأمهات المؤمنين وأذكار وآيات للتدبر.

تُحفظ متابعة الأجزاء والأحاديث في التخزين المحلي للمتصفح على الجهاز نفسه، ولا توجد حسابات أو مزامنة سحابية.

## حدود المحتوى والسلامة

هذه نسخة أولية مفيدة للتصفح والتعلم، وليست موسوعة شاملة أو مصحفًا كاملًا أو خدمة فتوى. لا يمكن حصر كل الصالحين أو جميع المسائل الفقهية. الأحاديث والسير مختارة، وأرقام المراجع قد تختلف باختلاف الطبعات؛ راجع النص والسياق والتخريج في المصدر الأصلي. المساعد الفقهي لا يتصل بخدمة ذكاء اصطناعي. المسائل الشخصية، والطلاق، والميراث، والعقود تستلزم سؤال مختص مؤهل.

## طريق الإكمال

1. مراجعة شرعية تحريرية لكل نص ومرجع.
2. ربط الحفظ بقاعدة مصحف موثوقة ومرخصة وإضافة تسجيل جلسات المراجعة.
3. نقل المحتوى إلى قاعدة بيانات قابلة للإدارة والبحث والتحديث.
4. حسابات ومزامنة اختيارية مع حماية الخصوصية.
5. مساعد معرفي لا يجيب إلا مع مصادر واضحة، مع مراجعة مختصين؛ لا توضع مفاتيح الخدمات في المتصفح.
6. قصص تفاعلية ومشاهد طبيعية ثلاثية الأبعاد دون تجسيد الأنبياء، بعد مراجعة المحتوى والتراخيص.
