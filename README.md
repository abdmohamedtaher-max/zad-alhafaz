# زاد — رفيق رحلتك الإيمانية

واجهة ويب عربية متجاوبة تشمل:
- لوحة متابعة لحفظ القرآن حسب الأجزاء الثلاثين، مع حفظ التقدم محليًا في المتصفح.
- مجموعة أولية من الأحاديث مع إحالات للمصادر.
- قصص موجزة مستلهمة من القرآن ومشاهد طبيعية ثلاثية الأبعاد تجريدية، دون تصوير الأنبياء.
- واجهة للمساعد الفقهي مع تنبيه واضح: النسخة الحالية لا تتصل بنموذج ذكاء اصطناعي ولا تقدم فتاوى.

## التشغيل

افتح `index.html` مباشرة في متصفح حديث، أو نزّل المشروع ZIP وفك الضغط ثم افتح الملف. تحتاج صفحة الخطوط إلى الإنترنت لتحميل خط عربي إضافي؛ وتعمل الواجهة أيضًا بخط النظام عند عدم توفر الاتصال.

## ملاحظات مهمة

- هذه نسخة واجهة أولية وليست مصحفًا كاملًا أو منصة فتاوى.
- تتبع الأجزاء هو تسجيل إنجاز يدوي؛ يلزم ربطه بمصحف موثوق لإضافة النصوص والتلاوة.
- المشاهد ثلاثية الأبعاد الحالية مؤثرات CSS تجريدية للطبيعة، وليست رسومًا متحركة ثلاثية الأبعاد متقدمة.
- إضافة مساعد ذكاء اصطناعي حقيقي تحتاج إلى خادم آمن ومصدر موثوق ومراجعة علمية. لا تضع مفاتيح API في ملفات المتصفح، ولا ينبغي أن يصدر النظام فتاوى ملزمة.
- تحقق من نصوص الأحاديث وإحالاتها في مصادر حديثية معتمدة، واستعن بأهل العلم في مسائل الفقه.
