# زاد

واجهة ويب عربية أولية لتنظيم رحلة حفظ القرآن والتعلّم من الحديث والسيرة والأذكار. تعمل الصفحات محليًا في المتصفح.

## التشغيل

افتح `index.html` في متصفح حديث. ومن الصفحة الرئيسية انتقل إلى:
- `library.html`: فهرس قصص الأنبياء وموضوعات الفقه ومصادر للرجوع.
- `heritage.html`: نماذج من سير الصحابة والتابعين وأمهات المؤمنين، وأذكار مختارة وآيات للتدبر.

تقدم الأجزاء وعلامات الأذكار تحفظ محليًا في المتصفح، ولا تتم مزامنتها بين الأجهزة.

## حدود النسخة

هذا إصدار أولي، وليس موسوعة كاملة أو مصحفًا كاملًا أو منصة فتوى. محتوى السير والأذكار مختار، وبعض الإحالات تحتاج إلى مراجعة تحريرية قبل اعتباره مادة منشورة نهائية. المساعد الفقهي لا يتصل بخدمة ذكاء اصطناعي. لا تستخدم التطبيق لإصدار أحكام على حالات شخصية؛ راجع عالمًا مؤهلًا أو جهة إفتاء موثوقة.

## خارطة طريق لاستكمال المشروع

1. مراجعة شرعية وتوثيق مستقل لكل نص ومرجع، وتصحيح أي خطأ قبل توسيع المحتوى.
2. ربط خطة الحفظ ببيانات مصحف مرخصة وموثوقة، وإضافة تقسيم آيات ومراجعة فعلية.
3. بناء مكتبة محتوى مفهرسة وقابلة للبحث بدل صفحات ثابتة.
4. إضافة حسابات ومزامنة آمنة اختيارية.
5. بناء مساعد معرفي يعتمد على مصادر مصرح بها ويعرض الإحالات، مع إحالة المسائل الشخصية إلى أهل الاختصاص؛ مفاتيح الخدمات تبقى على الخادم.
6. تطوير قصص تفاعلية ومشاهد طبيعية ثلاثية الأبعاد دون تجسيد الأنبياء، بعد مراجعة المحتوى والتراخيص.

لا يمكن عمليًا حصر كل سير الصالحين أو جميع المسائل الفقهية، ولا ينبغي ادعاء الشمول أو تقديم الفتوى آليًا.
