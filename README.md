# زاد الحفّاظ

تطبيق ويب بسيط باللغة العربية لحفظ القرآن الكريم والحديث الشريف ومتابعة المراجعة. يعمل محليًا داخل المتصفح ولا يحتاج إلى تثبيت أو اتصال بالإنترنت بعد تنزيله.

## التشغيل

1. نزّل المشروع بصيغة ZIP من صفحة GitHub.
2. فك ضغط الملف.
3. افتح `index.html` بمتصفح حديث.

يُحفظ التقدم على نفس الجهاز والمتصفح باستخدام التخزين المحلي. حذف بيانات المتصفح قد يؤدي إلى فقدان التقدم.

> محتوى الأحاديث للتدريب الأولي، لذا يُرجى مراجعة النص والتخريج من مصدر موثوق. التطبيق لا يغني عن التلقي على معلّم.
